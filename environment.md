## Окружение

- Python 3.12 (в GitHub Actions используется та же версия, см. `.python-version`).
- Зависимости с зафиксированными версиями — `requirements.txt`.
- SQLite входит в стандартную библиотеку Python (`sqlite3`), отдельная установка не нужна.
- Редактор кода (например, VS Code), Git, аккаунт GitHub с доступом к GitHub Actions.
- Для видеоотчёта — любая программа записи экрана (OBS Studio, встроенные средства ОС).

## Изолированность окружения

Способ изоляции выбирается студентом (venv, Poetry, uv). Пример с venv:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Пример с uv:

```bash
uv venv -p 3.12
uv pip install -r requirements.txt
```

Если вы добавляете новые зависимости, зафиксируйте их версии в `requirements.txt`, чтобы локальные проверки и GitHub Actions использовали одинаковое окружение.
