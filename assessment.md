# Критерии оценивания

Работу оценивает эксперт — автор топика. Отчётом является **видеоролик продолжительностью до 4 минут** вместе с репозиторием решения; корректность проверяется автоматизированными тестами (`tests/`) и историей запусков GitHub Actions.

## Проверяемые сценарии

**1. Обычная обработка** (`tests/test_basic.py`)
События приходят по порядку и по одному разу; статус и версия сделки обновляются, `GET /deals/{deal_id}` возвращает актуальное состояние.

**2. Повторная доставка** (`tests/test_idempotency.py`)
Повторное событие распознаётся как `duplicate` и не изменяет данные, в том числе после перезапуска сервиса.

**3. Нарушение порядка доставки** (`tests/test_ordering.py`)
Устаревшее событие (`version` не больше текущей) получает `stale` и не перезаписывает актуальные данные; события с одинаковой версией не перезаписывают друг друга.

**4. Сценарии из набора тестовых событий** (`tests/test_scenarios.py`)
Все сценарии `events/scenarios/*.json` дают ожидаемую последовательность ответов и итоговое состояние.

**5. Некорректные входные данные** (`tests/test_validation.py`)
Все примеры из `events/invalid` получают 422, не изменяют данные и не помечаются как обработанные.

## Шкала оценок

Оценка выставляется буквенная; в скобках — соответствие десятибалльной шкале.

| Оценка | Уровень                               | Что должно быть выполнено                                                                                                   |
|--------|---------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| **Э** (10)  | экспертный                       | Уровень П + конкурентная доставка и конфликт `event_id` (409): `tests/advanced/test_concurrency.py` проходит; в видео объяснено, какие гонки устранены и как |
| **П** (9)   | продвинутый                      | Уровень Б+ + проверка подписи webhook (HMAC): `tests/advanced/test_signature.py` проходит                                     |
| **Б+** (8)  | базовый с заделом                | Уровень Б + собственные тесты/сценарии (не менее 2); в видео объяснены атомарность обработки и ограничения решения          |
| **Б** (7)   | базовый                          | Все тесты базового уровня (`python -m pytest`) проходят локально и в GitHub Actions; видео показывает все сценарии          |
| **Б−** (6)  | базовый с некоторыми недостатками | Базовый уровень в целом выполнен, но есть недочёты: отдельные тесты не проходят, CI не настроен/красный или видео неполное |
| **У** (5)   | удовлетворительный               | Реализованы идемпотентность и версионирование, но валидация или часть сценариев не работают                                 |
| **Н** (4)   | недостаточный                    | Реализована только часть задания (например, лишь идемпотентность); видео отсутствует или не демонстрирует работу           |
| **К** (3)   | критический                      | Решение не запускается, тесты изменены под решение или работа не сдана                                                      |

Дополнительно снижают оценку:

- изменение существующих тестов или файлов в `events/` (допускается только добавление новых);
- решение, подогнанное под конкретные тесты, а не опирающееся на механизмы БД (ограничения, транзакции, условные обновления);
- видео длиннее 4 минут.

## Формат обратной связи

По каждой работе эксперт даёт обратную связь в виде списка замечаний. У каждого замечания указан диапазон оценки, которого оно касается, итоговая оценка выставляется по совокупности замечаний.

Пример:

```
1. Идемпотентность реализована через UNIQUE-ограничение, дубликаты корректно распознаются после перезапуска.   Э–Э
2. Проверка версии и запись события выполняются в разных транзакциях — возможна гонка.                         Э–П
3. Собственные тесты добавлены, но покрывают только обычную доставку.                                          П–Б+
4. В видео не показана обработка некорректных данных.                                                          Б+–Б+
........................................................................................ итог: Б+
```
